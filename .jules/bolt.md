## 2024-05-24 - Pandas .iloc performance in tight loops
**Learning:** Pandas `.iloc` has massive overhead when called repetitively inside tight iterative loops (like iterating over rows or building list comprehensions). In our tests, switching from `.iloc` to NumPy array `.values` access yielded a ~40x speedup in `get_extrema` and a ~5x speedup in `find_divergences`. Also, simple function calls (like `in_range`) inside deep nested loops add up quickly; inlining them provides a ~2x speedup for that specific operation.
**Action:** When performing iterative lookups on a DataFrame in tight loops, always extract the column to a NumPy array beforehand using `df['Col'].values` and index into the array instead of using `df['Col'].iloc[idx]`. Prefer inline conditionals over helper functions for very simple checks in critical paths.
